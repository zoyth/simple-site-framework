# Changelog

All notable changes to this project will be documented in this file.

The format is based on [Keep a Changelog](https://keepachangelog.com/en/1.0.0/),
and this project adheres to [Semantic Versioning](https://semver.org/spec/v2.0.0.html).

## [1.0.0] - 2025-02-05

### Added

- **Core Components**: Full suite of section components (HeroSection, FeaturesGrid, ServicesSection, TestimonialSection, ContactSection, CTASection, AboutSection, FAQAccordion, PricingTable, and more)
- **Layout Components**: Header, Footer, LanguageSelector, Breadcrumb
- **UI Components**: Button, Card, Input, Textarea, Select, Modal, Tabs, Toast, Skeleton, LoadingSpinner
- **Form Components**: ContactForm, FormField, MultiStepForm, FileUpload with validation
- **Conversion Components**: MobileCTA, ExitIntentModal, CountdownTimer, StickyBar, LiveProof, TrustBadges
- **Analytics Integration**: AnalyticsTracker, TrackedLink, A/B testing utilities
- **SEO Components**: SEOMetaTags, StructuredData, I18nMetaTags
- **Internationalization**: Full i18n support with LocalizedString type, locale routing, language detection
- **Performance Features**: LazySection, AnimatedSection with Framer Motion integration
- **Accessibility**: WCAG 2.1 AA compliant components with ARIA support
- **CLI Tools**: create-simple-site scaffolding command
- **Documentation**: Comprehensive docs for all components and features

### Notes

This is the first stable release published to NPM. Previous versions were consumed directly from GitHub.
